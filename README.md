# About Nina

在前端訓練課程結束後，獨立完成的個人練習作品。
使用 Vue 3 和 Tailwind CSS 開發，打造出一個具有個人特色的簡介網站。

## 使用技術

- [Vue 3](https://vuejs.org/) + Composition API
- [Tailwind CSS](https://tailwindcss.com/) — 快速建構響應式網頁
- [Animate.css](https://animate.style/) — 元素進場動畫
- [GitHub Pages](https://pages.github.com/) — 靜態網站部署

## 專案功能

- 使用 Vue Composition API 撰寫元件化架構
- 響應式版面設計，支援桌機與手機
- 具動畫效果的使用者體驗
- 清晰的資訊區塊分段，包括：
  - 自我介紹
  - 技能展示
  - 工作經歷

## 新增功能：留言板

- 使用 MockAPI 模擬後端儲存留言資料
- 訪客可輸入暱稱與留言內容
- SweetAlert 彈窗提示送出或刪除留言
- 留言即時渲染，依時間由新至舊排列

## 注意事項

- 本專案為個人練習作品，無商業用途
- 未來將持續優化 UI/UX 並擴充功能
